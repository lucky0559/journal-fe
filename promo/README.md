# Journ.al promo video

A 29 second promo for the app with voiceover, made with [Remotion](https://www.remotion.dev), in two shapes from the same scenes:

- `JournalPromo`: vertical 1080 x 1920 (Reels, Shorts, TikTok, stories)
- `JournalPromoWide`: 16:9 1920 x 1080 (YouTube, websites); scenes switch to two-column layouts via `useWide()`

The app screens are recreated in code with the real Lamplight colours and fonts (Caprasimo, Figtree), so no personal
journal pages appear in it.

Scenes (`src/scenes/`): Hook, Mood, Write, Month, Private, Outro, joined with slide transitions over one shared backdrop
(`src/Promo.tsx`). Colours, fonts and the mood colour/shape helpers live in `src/theme.ts`.

## Audio

The music and sound effects are original and generated by `scripts/make-audio.mjs` (pure Node, no samples): a warm lo-fi
loop at 90 BPM (one bar = 80 frames, so every scene cut lands on the beat grid and the outro lands on the home chord),
plus whooshes, taps, typing, a paper thud, a switch, tuned pops, a calendar shimmer and an icon chime. The script writes
`public/audio/*.wav`; `Soundtrack` in `src/Promo.tsx` places each sound on its frame.

The voiceover is ElevenLabs ("Matilda", `eleven_multilingual_v2`), seven clips made by `scripts/make-voiceover.mjs` into
`public/voiceover/*.mp3` and levels them into `*.wav` (same speech loudness for every line); the lines and their start
frames are in `VOICEOVER` in `src/Promo.tsx`, and the music dips to 30% under each line. `--level` re-levels without
calling the API. Regenerating needs `ELEVENLABS_API_KEY` in `promo/.env` (gitignored); set `VOICE_ID` to try
another voice. If a new clip runs longer, check it still ends before the next scene's line.

```bash
npm i
node --env-file=.env scripts/make-voiceover.mjs                           # regenerate the voiceover (optional)
node scripts/make-audio.mjs                                               # regenerate the audio (optional)
npx remotion studio                                                       # preview and edit
npx remotion render JournalPromo out/journal-promo.mp4 --crf=16           # vertical
npx remotion render JournalPromoWide out/journal-promo-16x9.mp4 --crf=16  # 16:9
```

If you change a scene's length, move the cut points and sound cues in `src/Promo.tsx` with it.
